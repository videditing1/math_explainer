# Beat outline (fill this in before writing script.txt)

From docs/01-why-these-videos-work.md. One idea per beat; ~180 wpm, so 30 s ≈ 80 words.

| # | Beat | Narration (what you hear) | Visual (what you see) | Cue word |
|---|---|---|---|---|
| 1 | **Hook**: the payoff or the question, in the first 3 s | | the hero visual or the question on screen | |
| 2 | **Gut guess**: what intuition says | | the guess, in grey (MUTED) | |
| 3 | **Reveal**: the surprising truth | | wrong guess crossed out, answer in SUBJECT colour | |
| 4 | **The why**: the single picture that explains it | | the one animation people will share | |
| 5 | **Formalise**: map each symbol to a piece of the picture | | formula assembled piece by piece | |
| 6 | **Payoff**: the number or idea to remember | | hold the final frame ≥ 1.4 s | |

Checklist
- [ ] Concrete example before any symbol
- [ ] One metaphor, never swapped mid-video
- [ ] Each colour means one thing for the whole video
- [ ] Every claim and number checked (put the check in a comment in scene.py)
- [ ] Simplifications labelled honestly ("≈", "roughly")
